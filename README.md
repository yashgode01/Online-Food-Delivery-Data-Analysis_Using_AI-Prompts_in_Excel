# Online Food Analysis - Ashoka Restaurant

## About the Project

This project focuses on analyzing an Online Food Delivery dataset to understand customer demographics, food delivery usage, customer behavior and feedback.

The dataset contains information such as age, gender, marital status, occupation, monthly income, education, family size, customer type, pin code, output and feedback.

## What I Did

I cleaned and prepared the dataset for analysis.

I analyzed the data using Excel to identify useful patterns and customer insights.

I created an Excel dashboard using charts, KPIs, pivot tables and filters.

I also used AI prompts to assist with data analysis and solving different business questions.

To verify the results, I manually solved the same questions in Excel and compared the results with the AI generated outputs.

## Tools Used

Microsoft Excel

AI Prompts

Pivot Tables

Charts and Visualizations

Excel Functions

## Key Objective

The main objective of this project is to understand customer behavior in online food delivery and present the findings through an easy to understand Excel dashboard.
